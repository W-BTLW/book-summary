## Chapter 10. 네트워크 기초

<br>

### 노드, 네트워크, 라우터
- 노드 : 데이터를 송수신하는 모든 장치
- 네트워크 : 각 노드가 데이터를 주고받기 위해 연결된 시스템
- 패킷 : 노드가 네트워크를 통해 전송하는 데이터의 단위 (헤더 + 페이로드)
- 라우터 : 네트워크 간에 패킷을 전송

<br>

### IP주소와 도메인
- IPv4 : 1바이트 4개의 숫자블록으로 이루어진 각 노드의 주소
- 도메인 : aka
- DNS : 도메인 이름과 IP주소로 변환하는 체계(인터넷 전화번호부)
- hosts파일이 도메인 서버보다 우선 매핑된다

<br>

##### 노드IP
- 고정IP
- 동적IP : DHCP서버를 통해 동적 IP를 발급받음


<br>

### NAT
- NAT ? 네트워크 주소를 변환하는 기술 (사설IP <-> 공인IP)
- SNAT (사설IP -> 공인IP)
- DNAT (공인IP -> 사설IP)

<br>

### VPN
- VPN ? 가상 사설 네트워크. 인터넷과 같은 공용 네트워크에서 서로 다른 네트워크 간에 암호화된 연결을 제공한다.

<br>

### 프로토콜과 TCP, UDP, QUIC
- 프로토콜 : 네트워크 상에서 두 노드가 데이터를 주고받기 위해 정의한 규칙

| 계층 | 프로토콜 |
| --- | --- |
| 애플리케이션 계층 | HTTP, FTP, SMTP |
| 전송 계층 | TCP, UDP |
| 네트워크 계층 | IP |
| 데이터 링크 계층 | |
| 물리 계층 | |

- TCP
  - 3-Way Handshake 과정을 통해 두 노드가 연결
  - 신뢰성 높음. (패킷 순서를 보장하고 패킷 유실 시, 재전송함)
  - 전송 속도는 느림 (ex. HOL 블로킹)
- UDP
  - 연결 과정 없이 바로 데이터 전송
  - 신뢰성 낮고, 순서 보장하지 않으나 빠르긴 함
- QUIC
  - 빠른 TCP + 신뢰성높은 UDP
  - 기본적으로 암호화되어 전송됨
  - 멀티플렉싱 지원 (한 연결에서 여러 스트림 동시에 처리 가능)
